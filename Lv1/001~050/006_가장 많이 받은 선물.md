해결 문제 이름 : 가장 많이 받은 선물 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/258712)

## [문제]
선물을 직접 전하기 힘들 때 카카오톡 선물하기 기능을 이용해 축하 선물을 보낼 수 있습니다. 당신의 친구들이 이번 달까지 선물을 주고받은 기록을 바탕으로 다음 달에 누가 선물을 많이 받을지 예측하려고 합니다.

- 두 사람이 선물을 주고받은 기록이 있다면, 이번 달까지 두 사람 사이에 더 많은 선물을 준 사람이 다음 달에 선물을 하나 받습니다.
  - 예를 들어 A가 B에게 선물을 5번 줬고, B가 A에게 선물을 3번 줬다면 다음 달엔 A가 B에게 선물을 하나 받습니다.
- 두 사람이 선물을 주고받은 기록이 하나도 없거나 주고받은 수가 같다면, 선물 지수가 더 큰 사람이 선물 지수가 더 작은 사람에게 선물을 하나 받습니다.
  - 선물 지수는 이번 달까지 자신이 친구들에게 준 선물의 수에서 받은 선물의 수를 뺀 값입니다.
  - 예를 들어 A가 친구들에게 준 선물이 3개고 받은 선물이 10개라면 A의 선물 지수는 -7입니다. B가 친구들에게 준 선물이 3개고 받은 선물이 2개라면 B의 선물 지수는 1입니다. 만약 A와 B가 선물을 주고받은 적이 없거나 정확히 같은 수로 선물을 주고받았다면, 다음 달엔 B가 A에게 선물을 하나 받습니다.
  - 만약 두 사람의 선물 지수도 같다면 다음 달에 선물을 주고받지 않습니다.

위에서 설명한 규칙대로 다음 달에 선물을 주고받을 때, 당신은 선물을 가장 많이 받을 친구가 받을 선물의 수를 알고 싶습니다.

친구들의 이름을 담은 1차원 문자열 배열 friends 이번 달까지 친구들이 주고받은 선물 기록을 담은 1차원 문자열 배열 gifts가 매개변수로 주어집니다. 이때, 다음달에 가장 많은 선물을 받는 친구가 받을 선물의 수를 return 하도록 solution 함수를 완성해 주세요.

## [해결 코드]
```csharp
public int solution(string[] friends, string[] gifts) 
{
    // 목표 : 다음 달에 가장 많은 선물을 받는 친구가 받을 선물의 수
    // 각 친구가 받을 선물의 수를 구해야 함
    // 각 친구들이 서로 주고 받은 선물을 비교해서 큰쪽이 하나 더 받음
        // 주고 받은 수가 같으면(0도 포함임) 선물 지수를 비교해서 높은족이 더 받음
        // 이마저도 같으면 서로 다음 달 선물을 주고받지 않음
    
    // 친구 객체는 string을 통해 Hash계산으로 O(1)의 속도로 찾을 수 있게 함 => Dictionary 사용
    // 각 친구가 받은 선물과 준 선물, 주어진 친구이름배열중에서 몇번째에 위치하는 지, 다음달에 받을 선물 갯수를 객체로 만들기
    // 선물을 준 것을 Dictionary로 누구에게 몇번 받았는지를 표시
    // 이중 for문으로 다음 달에 받을 선물을 계산
    
    // 친구들 객체로 만들기
    Dictionary<string, Friend> friendsDict = new Dictionary<string, Friend>();
    for(int i = 0; i < friends.Length; i++)
    {
        Friend someone = new Friend(i);
        friendsDict.Add(friends[i], someone);
    }
    
    // 서로 선물 주고 받은 내역 기록하기
    for(int logNum = 0; logNum < gifts.Length; logNum++)
    {
        string[] twoFriends = gifts[logNum].Split(' ');
        Friend giver = friendsDict[twoFriends[0]];
        Friend getter = friendsDict[twoFriends[1]];
        giver.GiveGift(getter.index);
        getter.GetGift();
    }
    
    // 친구들 배열로 줄세우기
    Friend[] fArr = new Friend[friends.Length];
    int arrCount = 0;
    foreach(Friend friend in friendsDict.Values)
    {
        fArr[arrCount++] = friend;
    }
    
    // 서로 다음달에 주고 받을 선물 계산하기
    // 서로 겹치지 않도록 내부 for문 시작을 외부 포문 인덱스+1로 함
    for(int i = 0; i < fArr.Length; i++)
    {
        Friend left = fArr[i];
        for(int x = i + 1; x < fArr.Length; x++)
        {
            Friend right = fArr[x];
            int leftGiveToRight = left.HowManyGiftTo(right.index);
            int rightGiveToLeft = right.HowManyGiftTo(left.index);
            
            if(leftGiveToRight > rightGiveToLeft){left.nextMonthGift++; continue;}
            else if(leftGiveToRight < rightGiveToLeft){right.nextMonthGift++; continue;}
            
            if(left.getGiveDiff > right.getGiveDiff){left.nextMonthGift++;}
            else if(left.getGiveDiff < right.getGiveDiff){right.nextMonthGift++;}
        }
    }
    
    // 가장 높은 선물 수 찾아서 반환
    int mostHighGiftCount = 0;
    for(int i = 0; i < fArr.Length; i++)
    {
        if(fArr[i].nextMonthGift > mostHighGiftCount)
        {
            mostHighGiftCount = fArr[i].nextMonthGift;
        }
    }
    return mostHighGiftCount;
}

public class Friend
{
    public int index = 0;
    public int receivedGift = 0;
    public int givedGift = 0;
    public int nextMonthGift = 0;
    public Dictionary<int, int> getGiftLogDict = new Dictionary<int, int>();
    
    public Friend(int fIndex)
    {
        index = fIndex;  
    }
    
    public void GiveGift(int getter)
    {
        if(getGiftLogDict.ContainsKey(getter))
        {
            getGiftLogDict[getter]++;
        }
        else
        {
            getGiftLogDict.Add(getter, 1);
        }
        givedGift++;
    }
    public void GetGift()
    {
        receivedGift++;
    }
    
    public int HowManyGiftTo(int getter)
    {
        getGiftLogDict.TryGetValue(getter, out int getCount);
        return getCount;
    }
    
    public int getGiveDiff => givedGift - receivedGift;
}
```

다른 사람은 선물을 주고 받은 기록을 2차원 배열로 관리하였다. 
또 나는 선물을 주고받을 조건을 비교해서 줄 누군가를 골라 주는 방식을 사용했는데, 다른 사람은 한 사람씩 검사해서 받을 조건이 되는지를 검사하여 조건이 되면 주었다. 그 결과 답을 도출해내기까지 상당부분 불필요한 부분을 덜어내었다.

내 방식은 문제의 상황을 모두 표현하려는 것이었고, 다른 사람의 방식은 판단에 필요한 정보만 확실히 구분해 내어 구현한 것이었다. 다음 풀이부터는 구현을 시작하기에 앞서 문제의 조건을 확실히 하는 연습을 해야겠다.
