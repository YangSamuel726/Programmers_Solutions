해결 문제 이름 : 유연근무제 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/388351)

## [문제]
프로그래머스 사이트를 운영하는 그렙에서는 재택근무와 함께 출근 희망 시각을 자유롭게 정하는 유연근무제를 시행하고 있습니다. 제도 정착을 위해 오늘부터 일주일 동안 각자 설정한 출근 희망 시각에 늦지 않고 출근한 직원들에게 상품을 주는 이벤트를 진행하려고 합니다.

직원들은 일주일동안 자신이 설정한 출근 희망 시각 + 10분까지 어플로 출근해야 합니다. 예를 들어 출근 희망 시각이 9시 58분인 직원은 10시 8분까지 출근해야 합니다. 단, 토요일, 일요일의 출근 시각은 이벤트에 영향을 끼치지 않습니다. 직원들은 매일 한 번씩만 어플로 출근하고, 모든 시각은 시에 100을 곱하고 분을 더한 정수로 표현됩니다. 예를 들어 10시 13분은 1013이 되고 9시 58분은 958이 됩니다.

당신은 직원들이 설정한 출근 희망 시각과 실제로 출근한 기록을 바탕으로 상품을 받을 직원이 몇 명인지 알고 싶습니다.

직원 n명이 설정한 출근 희망 시각을 담은 1차원 정수 배열 schedules, 직원들이 일주일 동안 출근한 시각을 담은 2차원 정수 배열 timelogs, 이벤트를 시작한 요일을 의미하는 정수 startday가 매개변수로 주어집니다. 이때 상품을 받을 직원의 수를 return 하도록 solution 함수를 완성해주세요.

## [해결 코드]
```csharp
public int solution(int[] schedules, int[,] timelogs, int startday) 
{
    // 목표 : 상을 받을 직원의 '수'
    // 주말 index 구하기
    // '정한 출근 시간'을 '주말을 제외한 평일'에 '모두' 지켰는지를 확인해야 함
    // 각 직원 확인을 for문으로 반복 검사
    // 정한 출근 시간을 변수로 두고 주말을 제외한 평일을 for문으로 돌려 출근시간 비교하기
        // 지켰으면 결과 count 늘리기
        // 못지킨 항목이 발생하면 즉시 break;
    // count 반환
    
    int saturday = (6 - startday + 7) % 7;
    int sunday = (7 - startday + 7) % 7;
    
    int workerLength = schedules.Length;
    int goodWorkerCount = 0;
    
    for(int worker = 0; worker < workerLength; worker++)
    {
        int planTime = schedules[worker] + 10;
        if(planTime % 100 >= 60) planTime += 40;
        bool isGoodWorker = true;
        for(int day = 0; day < 7; day++)
        {
            if(day == saturday || day == sunday) continue;
            if(timelogs[worker,day] > planTime)
            {
                isGoodWorker = false;
                break;
            }
        }
        if(isGoodWorker) goodWorkerCount++;
    }
    return goodWorkerCount;
}
```

## [후기]
풀이시간 : 38분 18초

토요일과 일요일 index를 구하는 것이 까다로웠다. 이런 값을 구하는데에 대입검증을 꼭 진행해야겠다. 순환 인덱스 계산 방식을 사용하였다.

정한 시간에 10분을 추가하는 과정이 어려웠다. 시간을 100단위로 옮겨버리니 십의 자리를 관리하는 것이 까다로웠다.
