해결 문제 이름 : 동영상 재생기 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/340213)

## [문제]

당신은 동영상 재생기를 만들고 있습니다. 당신의 동영상 재생기는 10초 전으로 이동, 10초 후로 이동, 오프닝 건너뛰기 3가지 기능을 지원합니다. 각 기능이 수행하는 작업은 다음과 같습니다.

- 10초 전으로 이동: 사용자가 "prev" 명령을 입력할 경우 동영상의 재생 위치를 현재 위치에서 10초 전으로 이동합니다. 현재 위치가 10초 미만인 경우 영상의 처음 위치로 이동합니다. 영상의 처음 위치는 0분 0초입니다.
- 10초 후로 이동: 사용자가 "next" 명령을 입력할 경우 동영상의 재생 위치를 현재 위치에서 10초 후로 이동합니다. 동영상의 남은 시간이 10초 미만일 경우 영상의 마지막 위치로 이동합니다. 영상의 마지막 위치는 동영상의 길이와 같습니다.
- 오프닝 건너뛰기: 현재 재생 위치가 오프닝 구간(op_start ≤ 현재 재생 위치 ≤ op_end)인 경우 자동으로 오프닝이 끝나는 위치로 이동합니다.

동영상의 길이를 나타내는 문자열 video_len, 기능이 수행되기 직전의 재생위치를 나타내는 문자열 pos, 오프닝 시작 시각을 나타내는 문자열 op_start, 오프닝이 끝나는 시각을 나타내는 문자열 op_end, 사용자의 입력을 나타내는 1차원 문자열 배열 commands가 매개변수로 주어집니다. 이때 사용자의 입력이 모두 끝난 후 동영상의 위치를 "mm:ss" 형식으로 return 하도록 solution 함수를 완성해 주세요.

## [해결 코드]

```csharp
public string solution(string video_len, string pos, string op_start, string op_end, string[] commands) 
{
    // 목표 : 마지막 재생 위치를 mm:ss 형태로 반환하기 
    // 코드 상으로 시간계산을 편하게 하기 위해 모두 초단위로 환산하기
    // 명령어를 switch문으로 받아서 커맨드 배열의 길이만큼 반복하기
    int curTime = StringToTime(pos);
    int videoLength = StringToTime(video_len);
    int opStart = StringToTime(op_start);
    int opEnd = StringToTime(op_end);
    
    if(curTime >= opStart && curTime < opEnd)
    {
        curTime = opEnd;
    }
    
    for(int i = 0; i < commands.Length; i++)
    {
        string command = commands[i];
        switch(command)
        {
            case "next":
                curTime = Math.Min(curTime + 10, videoLength);
                break;
            case "prev":
                curTime = Math.Max(curTime - 10, 0);
                break;
        }
        if(curTime >= opStart && curTime < opEnd)
        {
            curTime = opEnd;
        }
    }

    return GetFormatTime(curTime);
}

public int StringToTime(string timeString)
{
    int[] ms = Array.ConvertAll(timeString.Split(':'), int.Parse);
    return ms[0] * 60 + ms[1];
}

public string GetFormatTime(int time)
{
    int minuite = time / 60;
    int second = time % 60;
    return $"{minuite:D2}:{second:D2}";
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

- 시간초를 계산하기 위해 string에서 int로 바꾸어 계산함. 반복 동작이기에 따로 함수로 빼서 사용하였음.
- 명령어 배열에 있는 모든 명령어를 실행하기 위해 for문을 사용하였음
- 각 명령어에 따른 로직을 switch문을 통해 실행했음.
- 시간 증감에 따른 비디오 길이 초과나 0초 미만은 Math 함수를 이용하여 범위를 넘어서지 않도록 함
- 오프닝 구간확인은 초기에도 한번 해줘야 했음. 이후 명령어 실행시마다 구간확인을 다시 함
