해결 문제 이름 : 중요한 단어를 스포 방지 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/468370)

## [문제]
카카오톡은 메시지의 일부를 가려두었다가, 클릭했을 때만 공개되는 스포 방지 기능을 제공합니다. 이 기능을 활용하면 중요한 정보를 가리고 보낼 수 있습니다.

무지는 이 기능을 이용해 하나의 메시지 곳곳에 스포 방지 기능을 적용해 당신에게 보냈습니다. 당신은 메시지 시작부터 왼쪽 → 오른쪽 순서로 스포 방지 구간을 하나씩 클릭해 공개되는 단어들 중, 중요한 단어가 몇 개인지 확인하려 합니다.

### 단어 및 중요한 단어 규칙

- 단어는 공백으로 구분되며, 알파벳 소문자와 숫자로만 구성된 연속된 문자열입니다.
- 단어를 구성하는 문자들의 인덱스 중 하나 이상이 스포 방지 구간에 포함될 경우, 해당 단어는 스포일러 방지 단어로 간주합니다. 즉, 단어 내 일부 문자에만 스포일러 방지 기능이 적용되더라도, 해당 단어 전체를 스포일러 방지 단어로 간주합니다.
- 한 단어가 여러 개의 스포 방지 구간에 걸쳐 있을 수 있으며, 하나의 스포 방지 구간에 여러 단어가 포함될 수 있습니다.
- 스포 방지 구간을 클릭해 단어의 모든 문자가 공개되었을 때, 그 단어가 아래 조건을 모두 만족하면 중요한 단어입니다.
  1. 스포 방지 단어여야 합니다.
  2. 메시지의 스포 방지 구간이 아닌 구간(= 어떤 스포 방지 구간에도 속하지 않는 모든 구간: 각 구간의 앞·사이·뒤 포함)에 등장한 적이 없어야 합니다.
  3. 이전에 공개된 스포 방지 단어와 중복되지 않아야 합니다.
  4. 여러 단어가 동시에 공개된 경우, 왼쪽부터 순서대로 하나씩 중요한 단어인지 판단합니다.

무지가 당신에게 보내온 메시지를 나타내는 문자열 message와 스포 방지가 적용된 구간을 나타내는 2차원 정수 배열 spoiler_ranges가 매개변수로 주어질 때, 스포 방지 단어 중 중요한 단어의 수를 return 하도록 solution 함수를 완성해 주세요.

## [해결 코드]
```csharp
public int solution(string message, int[,] spoiler_ranges) 
{
    // 모든 문자열을 검색해서 문자열의 어느 범위에 속하는지 검사
    // 각 문자열이 스포 방지 구간에 속하는지 검사
        // 1. 속하면 중요단어 HashSet에 저장
        // 2. 아니면 일반단어 HashSet에 저장
        // HashSet에 저장함으로 중복단어 조건을 지킴
    // 일반단어 HashSet에 중요단어가 속하는지 count를 셈
    // 중요단어 문자수에 count를 뺀 값을 반환
    
    int startIndex = 0;
    int lastIndex = 0;
    StringBuilder word = new StringBuilder();
    
    int allWordCount = message.Trim().Split(' ').Length;
    string[] allWords = new string[allWordCount];
    int[] wordStartIndex = new int[allWordCount];
    int[] wordEndIndex = new int[allWordCount];
    
    int findWordCount = 0;
    for(int i = 0; i < message.Length; i++)
    {
        lastIndex = i;
        
        if(message[lastIndex] == ' ') continue;
        
        if(word.Length == 0) startIndex = i;
        word.Append(message[lastIndex]);
        
        if(lastIndex + 1 == message.Length || message[lastIndex + 1] == ' ')
        {
            allWords[findWordCount] = word.ToString();
            wordStartIndex[findWordCount] = startIndex;
            wordEndIndex[findWordCount] = lastIndex;
            
            word.Clear();
            findWordCount++;
            continue;
        }
    }
    
    HashSet<string> genericWords = new HashSet<string>();
    HashSet<string> importantWords = new HashSet<string>();
    for(int i = 0; i < allWordCount; i++)
    {
        int left = wordStartIndex[i];
        int right = wordEndIndex[i];
        
        bool isImportantWord = false;
        for(int r = 0; r < spoiler_ranges.GetLength(0); r++)
        {
            int spoLeft = spoiler_ranges[r,0];
            int spoRight = spoiler_ranges[r,1];
            
            if(right >= spoLeft && left <= spoRight)
            {
                isImportantWord = true;
                break;
            }
        }
        if (isImportantWord)
        {
            importantWords.Add(allWords[i]);
        }
        else
        {
            genericWords.Add(allWords[i]);
        } 
    }
    
    int removeCount = 0;
    foreach(var w in importantWords)
    {
        if(genericWords.Contains(w)) removeCount++;
    }
    
    return importantWords.Count - removeCount;
}
```

 ### 초기 해결 과정
 목표 : 문자열을 검사하여 중요한 단어의 수를 반환해야 한다.
- 문자열 처음부터 한 문자씩 인덱스 접근으로 처리하되 ' ' 공백 문자를 만나면 해당 범위를 단어 처리함
- 단어 처리는 index 변수 두개를 사용하여 하나를 증가시키면서 공백을 만나면 단어처리 후 갱신 함
- 단어처리 중에는 구간에 따라 중요한 단어 HashSet이나 일반 단어 HashSet에 저장하도록 함
- 마지막으로 중요한 단어 HashSet의 각 단어를 일반 단어 HashSet에 포함되는지를 검사하여 제거함.
- 중요한 단어 HashSet Count 반환.
