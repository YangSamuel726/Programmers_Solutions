## [문제]
(너무 길어요.. 링크 참조)

## [해결 코드]
```csharp
public int[] solution(string[] wallpaper) 
{
    int lux = wallpaper[0].Length, luy = wallpaper.Length;
    int rdx = 0, rdy = 0;
    
    for(int y = 0; y < wallpaper.Length; y++)
    {
        for(int x = 0; x < wallpaper[0].Length; x++)
        {
            if(wallpaper[y][x] == '.') continue;
            
            if(x < lux) lux = x;
            if(x+1 > rdx) rdx = x+1;
            if(y < luy) luy = y;
            if(y+1 > rdy) rdy = y+1;
        }
    }
    int[] answer = new int[4] {luy, lux, rdy, rdx};
    return answer;
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

 목표 : 드래그의 각 왼쪽위와 오른쪽아래 포인트를 4크기의 정수배열로 반환

- 최소 크기의 드래그로 모든 파일을 선택하려면 파일들의 위치 중에서 최솟값과 최댓값을 구해서 반환하면 된다.
- 그러려면 각 파일을 모두 확인해야 하고 이는 모든 좌표를 확인해야 한다는 것이다.
- 파일을 찾으면 현재 왼쪽위 포인트보다 작으면 갱신 현재 오른쪽 아래보다 크면 갱신하는 형태로 갱신 로직을 진행한다.
- 파일을 모두 순회했으면 갱신된 포인트를 정수 배열로 반환한다.
