## [문제]
정수 l과 r이 주어졌을 때, l 이상 r이하의 정수 중에서 숫자 "0"과 "5"로만 이루어진 모든 정수를 오름차순으로 저장한 배열을 return 하는 solution 함수를 완성해 주세요.

만약 그러한 정수가 없다면, -1이 담긴 배열을 return 합니다.

## [해결 코드]
```csharp
public int[] solution(int l, int r) 
{
    List<int> list = new List<int>();
    int start = l + (5 - l % 5) % 5;
    for(int i = start; i <= r; i += 5)
    {
        string intString = i.ToString();
        bool willAdd = true;
        foreach(char c in intString)
        {
            if(c != '0' && c != '5')
            {
                willAdd = false;
                break;
            }
        }
        if(willAdd == true) list.Add(i);
    }
    return list.Count == 0 ? new int[] {-1} : list.ToArray();
}
```

## [문제 해결 과정]

목표 : l과 r 사이에 존재하는 0과 5만 포함되는 정수 배열 반환하기
1. for문을 돌면서 l과 r 사이에 있는 정수들을 검사하되 l을 5의 배수로 올림하여 검사를 시작하고 증감식에서 5를 더하여 증가시킬 것
2. 내부에서 foreach문으로 정수를 string으로 바꿔서 각 문자가 0혹은 5인지 확인하여 모두 통과하면 list에 추가
3. list의 Count값을 검사하여 요소가 없으면 -1이 담긴 배열, 있으면 list를 int 배열로 변환하여 반환


## [후기]
풀이시간 : 21분

배열을 미리 크기를 선언할 수 없었기에 가변 배열인 List를 사용하여 해당하는 값들을 모아두기로 결정했다.

l과 r사이의 모든 숫자가 아닌 5의 배수로 늘려가며 검사하였다. 이를 위해 시작 값을 l을 5의 배수로 올림한 값으로 정했다.

모든 자리수를 검사하기보다 문자열로 변환하여 각 문자가 0, 5에 해당하는지를 검사했다.

List의 Count값으로 -1이 든 배열을 반환할지 검사하였다.


다른 사람은 5의 배수로 올림 문제를 while을 통해 l에 후위 연산자로 더해 5의 배수가 될때까지 하였다.
```csharp
while(l % 5 != 0)
{
    ++l;
}
```
