## [문제]

1부터 6까지 숫자가 적힌 주사위가 세 개 있습니다. 세 주사위를 굴렸을 때 나온 숫자를 각각 a, b, c라고 했을 때 얻는 점수는 다음과 같습니다.

- 세 숫자가 모두 다르다면 a + b + c 점을 얻습니다.
- 세 숫자 중 어느 두 숫자는 같고 나머지 다른 숫자는 다르다면 (a + b + c) × (a2 + b2 + c2 )점을 얻습니다.
- 세 숫자가 모두 같다면 (a + b + c) × (a2 + b2 + c2 ) × (a3 + b3 + c3 )점을 얻습니다.

세 정수 a, b, c가 매개변수로 주어질 때, 얻는 점수를 return 하는 solution 함수를 작성해 주세요.

## [해결 코드]

```csharp
public int solution(int a, int b, int c)
{
    int answer = 0;
    if(a == b && b == c)
    {
        answer = 27 * a * a * a * a * a * a;
    }
    else if (a == b || b == c || c == a)
    {
        answer = (a + b + c) * (a*a + b*b + c*c);
    }
    else
    {
        answer = a + b + c;
    }
    return answer;
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

순서 : 어느 숫자가 같은지 검사 - 점수식 계산 - 점수 반환

1. 숫자 중 어느 것이 같은지를 if문으로 조건 분기 하였다.

2. 각각의 연산을 if문 안에 일일히 구현하였다.

## [후기]

풀이시간 : 10분 10초

어떤 사람은 첫 줄부터 a~c가 같은지를 전부 검사해서 count를 내놓는 사람이 있었다. 그 count를 기반으로 점수식을 실행하였다. 가독성이 좋다.

그리고 어떤 사람은...

```csharp
int answer = 1;
for(int i = ((a == b || a == c) ? 1 : 0) + ((b == c) ? 1 : 0) + 1; i != 0; i--)
    answer *= (int)(Math.Pow(a, i) + Math.Pow(b, i) + Math.Pow(c, i));
return answer;
```

이게 뭐냐...
자세히 살펴보면 for문의 `i` 값을 a~c가 같은지를 검사하여 추가하고 답변으로 제곱을 `i`번만큼 한 값을 더하였다. 이걸 `i--`를 수행하며 반복하였다. 엄청.. 간단하기는 엄청 간단하다.
