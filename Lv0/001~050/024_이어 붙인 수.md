## [문제]
정수가 담긴 리스트 num_list가 주어집니다. num_list의 홀수만 순서대로 이어 붙인 수와 짝수만 순서대로 이어 붙인 수의 합을 return하도록 solution 함수를 완성해주세요.

## [해결 코드]
```csharp
public int solution(int[] num_list) 
{
    // 목표 : 홀수만 순서대로 이어붙인 수와 짝수만 순서대로 이어붙인 수를 더한 값을 반환
    // 순서대로 이어붙일 홀수와 짝수의 문자열 변수를 생성
    // 반복문을 통해 배열을 돌면서 `% 2`로 짝수 홀수 판단 후 문자열에 이어붙이기
    // 문자열을 int.Parse하여 더하기
    string odd = "";
    string even = "";
    foreach(int num in num_list)
    {
        if(num % 2 == 0)
        {
            even += num;
        }
        else
        {
            odd += num;
        }
    }
    return int.Parse(even) + int.Parse(odd);
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

 - 순서대로 이어붙이는 작업을 문자열의 `+=`연산을 이용하여 해결
 - 짝수 홀수 판별을 `%2` 연산으로 해결
