## [문제]
길이가 같은 두 문자열 str1과 str2가 주어집니다.

두 문자열의 각 문자가 앞에서부터 서로 번갈아가면서 한 번씩 등장하는 문자열을 만들어 return 하는 solution 함수를 완성해 주세요.

## [해결 코드]
```csharp
public string solution(string str1, string str2) 
{
    StringBuilder sb = new StringBuilder(str1.Length*2);
    for(int i = 0; i < str1.Length; i++)
    {
        sb.Append(str1[i]);
        sb.Append(str2[i]);
    }
    return sb.ToString();
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

 길이가 같은 두 문자열이라는 조건이 있기에 StringBuilder의 초기 용량을 한 문자열의 길이의 2를 곱한 크기로 초기화했음.

 `str1`과 `str2`의 문자를 인덱스 0부터 Length-1까지 차례대로 번갈아가면서 넣으면 되기에 0부터 Length는 for문으로 표현했고 문자열 삽입 순서는 코드실행 순서로 표현했다.
