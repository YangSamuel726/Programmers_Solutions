해결 문제 이름 : 조건 문자열 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/181934)

## [문제]

문자열에 따라 다음과 같이 두 수의 크기를 비교하려고 합니다.

두 수가 n과 m이라면

- ">", "=" : n >= m
- "<", "=" : n <= m
- ">", "!" : n > m
- "<", "!" : n < m

두 문자열 ineq와 eq가 주어집니다. ineq는 "<"와 ">"중 하나고, eq는 "="와 "!"중 하나입니다. 그리고 두 정수 n과 m이 주어질 때, n과 m이 ineq와 eq의 조건에 맞으면 1을 아니면 0을 return하도록 solution 함수를 완성해주세요.

## [해결 코드]

```csharp
public int solution(string ineq, string eq, int n, int m)
{
    bool ineqb;
    bool eqb;
    if(ineq == "<")
    {
        ineqb = n < m;
    }
    else
    {
        ineqb = n>m;
    }
    if(eq == "=")
    {
        eqb = n == m;
    }
    else
    {
        eqb = false;
    }
    return ineqb || eqb ? 1 : 0;
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

각 문자열을 if문으로 검사해서 실제로 해당 조건 문자열을 하드코딩한 조건 검사문으로 바꾸어 `n`, `m`을 검사하여 결과값을 bool 변수에 저장하였다. 두 bool 변수 중에 하나만 만족해도 되기에 `||`연산자로 최종 검사하였다.

## [후기]

풀이시간 : 5분

다른 분은 조건 문자열을 합친 다음에 조건문을 4가지로 해서 결과값을 리턴하였다. 가독성이 상당히 좋다.

```csharp
int answer = 0;
string ie = ineq + eq;
if(ie == ">=") return n >= m ? 1 : 0;
if(ie == "<=") return n <= m ? 1 : 0;
if(ie == ">!") return n > m ? 1 : 0;
if(ie == "<!") return n < m ? 1 : 0;

return answer;
```
