## [문제]
연산 ⊕는 두 정수에 대한 연산으로 두 정수를 붙여서 쓴 값을 반환합니다. 예를 들면 다음과 같습니다.

- 12 ⊕ 3 = 123
- 3 ⊕ 12 = 312
  
양의 정수 a와 b가 주어졌을 때, a ⊕ b와 b ⊕ a 중 더 큰 값을 return 하는 solution 함수를 완성해 주세요.

단, a ⊕ b와 b ⊕ a가 같다면 a ⊕ b를 return 합니다.

## [해결 코드]
```csharp
public int solution(int a, int b) 
{
    int ab = int.Parse(a.ToString() + b.ToString());
    int  ba = int.Parse(b.ToString() + a.ToString());
    int answer = ab >= ba ? ab : ba;
    return answer;
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

a와 b를 붙여서 쓴 값을 반환하기 위해서 수학 공식이 아닌 문자열 변환을 통해서 붙인 다음 다시 정수값으로 `Parse()`하였다.

이후 두 값을 비교하여 더 큰 쪽을 리턴하는 문제는 삼항연산자의 특성을 이용해 풀었다.

## [후기]
풀이시간 : 3분 55초

다른 사람은 ToString()을 $"{a}{b}"로 풀어냈고 삼항연산자를 Math.Max를 통해 풀어냈다. 비용은 모르겠는데 가독성은 확실히 이쪽이 더 좋은것 같다.

```csharp
int aNum = Int32.Parse($"{a}{b}");
int bNum = Int32.Parse($"{b}{a}");
return Math.Max(aNum, bNum);
```
