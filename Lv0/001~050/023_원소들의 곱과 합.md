해결 문제 이름 : 원소들의 곱과 합 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/181929)

## [문제]
정수가 담긴 리스트 num_list가 주어질 때, 모든 원소들의 곱이 모든 원소들의 합의 제곱보다 작으면 1을 크면 0을 return하도록 solution 함수를 완성해주세요.

## [해결 코드]
```csharp
public int solution(int[] num_list) 
{
    int multiply = 1;
    int sum = 0;
    foreach(var num in num_list)
    {
        multiply *= num;
        sum += num;
    }
    return multiply < Math.Pow(sum, 2) ? 1 : 0;
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

 '모든 원소들의 곱'과 '모든 원소들의 합'을 구하기 위해 주어진 `num_list`를 foreach문으로 순회하며 '곱'과 '합'을 담당하는 변수에 연산을 하였다.

 이후 Math.Pow로 합의 제곱값을 구하고 삼항연산자를 통해 곱과 합제곱의 값을 비교하여 1 or 0을 반환하도록 하였다.

## [후기]
풀이시간 : 2분 40초

```csharp
answer = num_list.Aggregate(1, (x, y) => x * y) < Math.Pow(num_list.Sum(), 2) ? 1 : 0;
```
이렇게 푼 사람도 있었다.
