해결 문제 이름 : 등차수열의 특정한 항만 더하기 <br>
[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/181931)

## [문제]

두 정수 a, d와 길이가 n인 boolean 배열 included가 주어집니다. 첫째항이 a, 공차가 d인 등차수열에서 included[i]가 i + 1항을 의미할 때, 이 등차수열의 1항부터 n항까지 included가 true인 항들만 더한 값을 return 하는 solution 함수를 작성해 주세요.

## [해결 코드]

```csharp
public int solution(int a, int d, bool[] included)
{
    int answer = 0;
    for(int i = 0; i < included.Length; i++)
    {
        if(included[i] == false) continue;

        answer += a + d * i;
    }
    return answer;
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

1. 등차수열의 1항부터 n항까지 표현하기 위해 `for`문을 사용 하였다.

2. true인 항들만 더하기 위해 `for`문 첫 줄에 `included[i]` 조건 검사문을 넣었다.

3. 등차수열의 특징을 이용하여 (i+1)번째 등차수열의 값인 `a + d * i`값을 `answer`에 더하였다.

## [후기]

풀이시간 : 4분 50초

다른 사람은 Linq를 이용하여 문제를 해결하였다. 내 로직과 비용차이는 얼마나 날까?

```csharp
return Enumerable.Range(0, included.Length)
                         .Select(s => a + s * d)
                         .Where((w, index) => included[index])
                         .Sum();
```
