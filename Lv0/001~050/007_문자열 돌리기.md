## [문제]

문자열 str이 주어집니다.
문자열을 시계방향으로 90도 돌려서 아래 입출력 예와 같이 출력하는 코드를 작성해 보세요.

```
abcde
```

```
a
b
c
d
e
```

```csharp
static void Main()
{
    string s;
    s = Console.ReadLine();

    foreach(char c in s)
    {
        Console.WriteLine(c);
    }
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

문자열을 입력받아서 90도로 돌린다는 것은 문자열의 각 문자에 접근할 수 있어야 하고 줄바꿈을 해야 한다는 것으로 이해했다.

그렇기에 각 문자에 접근하기 위해 `foreach`문을 사용하였고, 줄바꿈과 출력을 동시에 하는 `WriteLine()`함수를 사용하였다.

## [후기]

풀이시간 : 20초

문자열의 각 문자에 접근할 수 있는지를 알아보는 문제인 듯 하다.

다른 사람은 입력을 받아서 `string.Join()`함수로 개행문자를 기존 입력 문자들 사이에 추가하여 단번에 출력하는 방법을 사용했다.

```csharp
    char[] input = Console.ReadLine().ToCharArray();
    string output = string.Join("\n", input);
    Console.WriteLine(output);
```

내 방법과 비교하면, `WriteLine()`함수의 호출 횟수 차이가 있고 입력 값을 읽은 후 `Join()` 함수 비용이 추가로 들었다.
