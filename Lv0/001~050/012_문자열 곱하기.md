## [문제]
문자열 my_string과 정수 k가 주어질 때, my_string을 k번 반복한 문자열을 return 하는 solution 함수를 작성해 주세요.

## [해결 코드]
```csharp
public string solution(string my_string, int k)
{
    StringBuilder sb = new StringBuilder(my_string.Length * k);
    for(int i = 0; i < k; i++)
    {
        sb.Append(my_string);
    }
    return sb.ToString();
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

 반환할 문자열의 크기가 `my_string.Length * k`로 고정되어 있기에 `sb`의 초기 용량을 해당 크기로 초기화하였다.
 
`sb`에 문자열을 반복 삽입하는 건 for문을 통해 k번 반복하였고 `my_string`의 문자열이 반복되어야 하기에 `Append()`인자에 문자열을 그대로 넣어주었다.

## [후기]
풀이시간 : 2분 10초

```
Enumerable.Range(0, k).Select(s => my_string).Aggregate((a, b) => a + b);
```
이렇게 푼 사람도 있었다. 이는 반복 연결 비용이 생긴다고 한다.

```
String repeat = String.Concat(Enumerable.Repeat(my_string, k));
```
이렇게 푼 사람도 있었다.
