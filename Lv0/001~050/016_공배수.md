[[문제 보러가기]](https://school.programmers.co.kr/learn/courses/30/lessons/181936)

## [문제]

정수 number와 n, m이 주어집니다. number가 n의 배수이면서 m의 배수이면 1을 아니라면 0을 return하도록 solution 함수를 완성해주세요.

## [해결 코드]

```csharp
public int solution(int number, int n, int m)
{
    int answer = 0;
    if(number % n == 0 && number % m == 0)
    {
        answer = 1;
    }
    return answer;
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

`number`를 나눈 나머지가 0이면 배수인 것을 이용해서 두 정수 `n`과 `m`을 각각 검사하여 두 조건이 모두 만족하면 `answer`에 1을 할당하여 반환하도록 하였다. 아닌 경우에는 `answer`의 기본값이 0이므로 그대로 반환하였다.

## [후기]

풀이시간 : 1분 35초

어떤 사람은 역으로 발상해서 두 조건중 하나라도 해당하지 않으면 그 자리에서 바로 0을 return하였다.

```csharp
if(number % n != 0) return 0;
if(number % m != 0) return 0;
return 1;
```
