## [문제]
정수 배열 arr와 2차원 정수 배열 queries이 주어집니다. queries의 원소는 각각 하나의 query를 나타내며, [s, e, k] 꼴입니다.

각 query마다 순서대로 s ≤ i ≤ e인 모든 i에 대해 k보다 크면서 가장 작은 arr[i]를 찾습니다.

각 쿼리의 순서에 맞게 답을 저장한 배열을 반환하는 solution 함수를 완성해 주세요.
단, 특정 쿼리의 답이 존재하지 않으면 -1을 저장합니다.

## [해결 코드]
```csharp
public int[] solution(int[] arr, int[,] queries) 
{
    int[] answer = new int[queries.GetLength(0)];
    for(int qi = 0; qi < queries.GetLength(0); qi++)
    {
        int kUpMin = 1000001;
        for(int s = queries[qi,0]; s <= queries[qi,1]; s++)
        {
            if(queries[qi,2] < arr[s] && arr[s] < kUpMin)
            {
                kUpMin = arr[s];
            }
        }
        
        if(kUpMin == 1000001) answer[qi] = -1;
        else answer[qi] = kUpMin;
    }
    return answer;
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

 1. 결과를 담을 쿼리 배열의 1차 길이 크기의 배열을 생성
 2. for문으로 각 순차적으로 돌며 쿼리 처리 (0 ~ queries.GetLength(0))
 3. arr에서 s와 e 사이에 있는 요소들을 확인하면서
    -k보다 큰 요소들 중 최소값을 결과 배열에 저장
    - 해당하는 요소가 없으면 -1 저장
