## [문제]

문자열 my_string, overwrite_string과 정수 s가 주어집니다. 문자열 my_string의 인덱스 s부터 overwrite_string의 길이만큼을 문자열 overwrite_string으로 바꾼 문자열을 return 하는 solution 함수를 작성해 주세요.

## [해결 코드]

```csharp
public string solution(string my_string, string overwrite_string, int s)
{
    StringBuilder sb = new StringBuilder();
    for(int i = 0; i<my_string.Length; i++)
    {
        if( i >= s && i < s+overwrite_string.Length)
        {
            sb.Append(overwrite_string[i-s]);
        }
        else
        {
            sb.Append(my_string[i]);
        }
    }
    return sb.ToString();
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

`s + overwrite_string.Length`는 my_string의 Length를 넘을 수 없는 제한사항이 있기에 my_string의 Length만큼 반복하여 문자를 StringBuilder 변수에 `Append()`하였다.
각 문자열에 인덱스 접근으로 문자를 가져오되 어떤 문자열에 접근해서 문자를 가져올지 if문으로 분기해서 정했다.

StringBuilder를 사용한 이유는 문자열이 길어질 경우 string으로 `+=`연산을 통해 값을 갱신하면 복사비용이 생기는 것을 우려했기 때문이다.
