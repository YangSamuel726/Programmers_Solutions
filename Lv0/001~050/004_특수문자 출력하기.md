## [문제]
다음과 같이 출력하도록 코드를 작성해 주세요.

<출력 예시>\
`!@#$%^&*(\'"<>?:;`

```csharp
static void Main()
{
    Console.WriteLine("!@#$%^&*(\\'\"<>?:;");
}
```

## [문제 해결 과정]
 ※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

1. 주어진 문자열을 `Console.WriteLine()`으로 출력하면 된다고 생각했다.
2. 다만 일반 문자열 리터럴에서 `\`와 `"`는 특별한 문법적 의미를 가지므로 별도로 표현해야 했다.
3. `\`는 이스케이프 시퀀스를 시작하는 기호이므로, 역슬래시 자체를 나타내기 위해 `\\`를 사용했다.
4. `"`는 문자열의 시작과 끝을 구분하므로, 문자열 내부의 큰따옴표를 나타내기 위해 `\"`를 사용했다.
5. 나머지 문자는 그대로 작성하여 한 번에 출력했다.

## [후기]
풀이시간 : 1분

문자열을 출력하는 방법과, 일반 문자열 리터럴에서 특별한 의미를 갖는 문자를 이스케이프 시퀀스로 표현하는 방법을 확인하는 문제였다.
