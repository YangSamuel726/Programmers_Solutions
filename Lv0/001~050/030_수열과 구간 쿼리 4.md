## [문제]

정수 배열 arr와 2차원 정수 배열 queries이 주어집니다. queries의 원소는 각각 하나의 query를 나타내며, [s, e, k] 꼴입니다.

각 query마다 순서대로 s ≤ i ≤ e인 모든 i에 대해 i가 k의 배수이면 arr[i]에 1을 더합니다.

위 규칙에 따라 queries를 처리한 이후의 arr를 return 하는 solution 함수를 완성해 주세요.

## [해결 코드]

```csharp
public int[] solution(int[] arr, int[,] queries)
{
    for(int qi = 0; qi < queries.GetLength(0); qi++)
    {
        int s = queries[qi,0];
        int e = queries[qi,1];
        int k = queries[qi,2];

        for(int i = s; i <= e; i++)
        {
            if(i%k == 0)
            {
                arr[i]++;
            }
        }
    }
    return arr;
}
```

목표 : 쿼리를 처리한 결과 arr를 반환

모든 쿼리를 확인하여 `s`이상 `e`이하인 정수 `i`에 대해 `k`의 배수이면 `arr[i]`에 1을 더한다.

1. for문으로 모든 쿼리를 확인
2. 조건 변수(s,e,k)를 선언 초기화
3. `s`와 `e`사이 모든 정수에 대해 k로 나눈 나머지를 확인하여 배수 확인
4. 배수이면 `arr[i]`에 1더하기
5. arr 반환
