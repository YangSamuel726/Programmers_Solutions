## [문제]

양의 정수 n이 매개변수로 주어질 때, n이 홀수라면 n 이하의 홀수인 모든 양의 정수의 합을 return 하고 n이 짝수라면 n 이하의 짝수인 모든 양의 정수의 제곱의 합을 return 하는 solution 함수를 작성해 주세요.

## [해결 코드]

```csharp
public int solution(int n) 
{
    int answer = 0;
    if(n % 2 == 0)
    {
        int k = n/2;
        answer = 2*k*(k+1)*(2*k+1)/3;
    }
    else
    {
        answer = (n+1)*(n+1)/4;
    }
    return answer;
}
```

## [문제 해결 과정]

※ 문제를 해결하는데 어떤 사고 과정을 거쳤는지, 어떤 자료구조 알고리즘을 왜 선택했는지 등 구체적인 근거를 설명할 수 있어야 함

n을 2로 나눈 나머지를 통해 짝수 홀수를 판별하고 짝수면은 짝수 제곱의 합을 구하는 공식과 홀수면은 홀수들의 합을 구하는 공식을 사용하여 문제를 해결하였다. 공식으로 단번에 풀었으므로 O(1)의 시간이 걸린다.

## [후기]

풀이시간 : 26분 50초

공식을 파악한다고 혼자서 땅굴을 깊이 팠다. 결국에 검색해서 적용했다.

다른 사람은 while문을 통해서 풀어냈다.
```csharp
int answer = 0;
while(n >=0)
{
    answer += n%2 == 0 ? n*n : n;            
    n -= 2;
}
return answer;
```
공식을 모르면 이 방식을 통해 풀 수 있겠지만 O(n)의 시간이 걸리는 단점이 있겠다.
