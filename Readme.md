## 코딩 테스트란 무엇인가?

코딩 테스트는 주어진 문제를 조건에 맞는 코드로 해결하는 능력을 확인하는 시험이다. 구체적으로는 다음 능력을 확인하기 위함이다.

- 문제 이해 : 요구사항과 제약을 정확히 파악하는가?
- 논리 구성 : 문제를 나누고 해결 방법을 찾는가?
- 구현 : 생각한 방법을 실제 코드로 작성하는가?
- 효율과 검증 : 적절한 자료구조를 선택하고 예외 상황까지 처리하는가?

## 왜 코딩 테스트를 하려고 했는가?

코딩 테스트를 하지 않아도 개발자를 할 수 있고 코딩을 할 수 있다. 그럼에도 하려는 이유는 **기초가 튼튼한 개발자, 고점이 높은 개발자**가 되기 위해서는 코딩 테스트라는 **훈련**이 도움이 될 것이라는 생각이 있었기 때문이다.

## 왜 Programmers를 선택했는가?

- 기초부터 유형별로 문제를 풀어나가는 길을 안내해주는 점.
- 코딩테스트 연습 문제를 무료로 이용할 수 있는 점
- C#을 지원하는 점.

## 어떤 식으로 공부할 것인가?

정답을 통과하는 데서 끝내지 않고, 풀이의 원리와 선택 이유를 스스로 설명하는 것을 목표로 한다.

1. 요구사항과 제약을 정리하고, 스스로 풀이를 시도한다.
2. 풀이 과정과 막힌 지점, 해결한 방법을 기록한다.
3. 자료구조를 선택한 이유와 시간·공간 복잡도, 예외 상황을 검토한다.
4. 다른 사람의 풀이와 AI의 설명을 비교하고, 코드 실행과 반례로 확인한다.
5. 도움을 받은 문제는 시간이 지난 뒤 해설 없이 다시 구현한다.

각 문제에서는 배울 점이 있는 항목을 중심으로 기록한다.
